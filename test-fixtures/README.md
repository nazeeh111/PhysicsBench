# Browser fixtures

`tracking.mp4` is a generated 2-second, 640×360 H.264 video. It contains no personal recording. Browser tests enter known coordinates to check decoding, media time, calibration units and exported metadata. Those coordinates are a software fixture, not a claim of measured physical motion.

`tracking-portrait.webm` is a generated 2-second, 360×640 VP8 video. It contains no personal recording. Browser tests use it to verify click mapping through the portrait frame's letterboxed canvas and to ensure rejected replacements preserve the active track.
